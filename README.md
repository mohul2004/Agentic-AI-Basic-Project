# KIIT Student Handbook Agent

An Agentic RAG (Retrieval-Augmented Generation) system built using:

- LangChain
- FAISS
- HuggingFace Embeddings
- Google Gemini

## Features

- Academic Regulations Search
- Examination Rules Search
- Hostel Rules Search
- Source-Based Answer Generation
- Answer Verification Agent
